SimpleMenu - Keyboard Navigation Demo

This example demonstrates SimpleMenu navigation containing both top-level links and buttons that open simple dropdowns. Use the navigation above with a pointer or keyboard.

Keyboard Reference

Key Behaviour
Tab / Shift+Tab Move through top-level links, buttons, and links in an open dropdown
Enter / Space Toggle a disclosure button or activate a link
Down / Right Move to the next item, or move from an expanded button to its first dropdown link
Up / Left Move to the previous item without wrapping
Home / End Move to the first or last item at the current level
Escape Close the current dropdown and return focus to its controlling button
