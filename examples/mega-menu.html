Mega Menu — Keyboard Navigation Demo

This example demonstrates the accessible mega-menu component. The Services and Our Work top-level items open div.c-mega-menu__container panels containing multiple columns of links. The About item uses a standard dropdown ul for comparison.

Keyboard Reference

Key Behaviour
Tab / Shift+Tab Move between top-level items; Shift+Tab from first panel link closes panel
↓ on top button Open panel and focus first link
↑ / ↓ inside panel Move between links within the panel
← / → inside panel Jump to previous / next top-level button
Escape inside panel Close panel, return focus to controlling button
Enter / Space Toggle panel open/closed
